### Hi there, I'm Mazharul 👋

I'm a software engineer from Bangladesh. I mostly work with WordPress, PHP and Laravel.

These days I'm working on some WordPress plugins:

- [Bit Flows](https://wordpress.org/plugins/bit-pi/) - automate tasks between your site and other apps
- [Bit Integrations](https://wordpress.org/plugins/bit-integrations/) - connect WordPress forms and plugins with other tools
- [Bit Social](https://wordpress.org/plugins/bit-social/) - share your posts to social media automatically

I also built [WP Validator](https://packagist.org/packages/bitapps/wp-validator), a small PHP package for validating and sanitizing data in WordPress. It works like Laravel's validation, so if you know Laravel you'll feel at home. It has 13k+ installs so far.

I recently published my first Chrome extension, [PopTranslate](https://chromewebstore.google.com/detail/poptranslate/hcohdcfpmiaikojodbgpnbhjnkldajjd). Just select any text and it shows the translation on the same page. It's open source, you can check the code [here](https://github.com/csemazharul/pop-translate).

I like open source and have contributed to [WordPress](https://github.com/WordPress/wordpress-develop), [Laravel](https://github.com/laravel/framework) and [WP Background Processing](https://github.com/deliciousbrains/wp-background-processing).

Still learning, still building. Thanks for stopping by!
